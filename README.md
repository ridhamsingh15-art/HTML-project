# BiteRush — Online Food Ordering Website

BiteRush is a front-end food-ordering website project created for the TR-101 Web Designing Mini Project at Guru Nanak Dev Engineering College, Ludhiana.

## Technologies
- HTML5 for page structure
- CSS3 for layout and responsive styling
- JavaScript for selected demo interface interactions

## Project scope
The website presents food categories, offers, restaurant and dish cards, and a simulated ordering experience. It is a front-end demonstration and does not provide real payments, a production database, or live delivery dispatch.

## Running locally
Open `index.html` in a modern browser.
